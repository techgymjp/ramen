# 行列のできるラーメン店

カウンター越しにやってくるお客さんの注文どおりにラーメンを作って出す、ブラウザで遊べるゲームです。
`index.html` を開くだけで遊べます（GitHub Pages でそのまま公開できます）。

## 遊び方（タップするもの）

1. 🥛 **水を出す** → お客さんをタップ（ラーメンは熱いので、水がないと食べてくれません）
2. 🍜 **茹で釜**をタップで麺を入れる
3. 🔔 **ピピッ**と鳴ったら茹で釜をタップで麺を出す（湯切りしてどんぶりへ）
4. 🥩 **トッピング**（チャーシュー・ネギ）を注文の数だけのせる
5. 🙋 注文した**お客さんをタップ**して出す

- ピピッの後に放っておいた茹ですぎの麺
- トッピングをのせすぎたラーメン、注文とちがうラーメン
