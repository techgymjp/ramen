# 行列のできるラーメン店

カウンター越しにやってくるお客さんの注文どおりにラーメンを作って出す、ブラウザで遊べるゲームです。
`index.html` を開くだけで遊べます（GitHub Pages でそのまま公開できます）。

## 遊び方（タップするもの）

1. 🥛 カウンター左の**コップ** → お客さんをタップで水を出す。いつでも出せます（ラーメンは熱いので、水がないと食べてくれません）
2. 🍜 厨房左の**麺茹で機**の空いている穴をタップで、てぼに麺を入れる（6玉まで同時に茹でられます）
3. 🥣 お客さんの数だけ厨房正面に空の**どんぶり**が出てきます。タップで**スープ**を入れる（スープがないと麺は入れられません）
4. 🔔 **ピピッ**と鳴ったてぼをタップ → チャッチャッと湯切りして、スープ入りのどんぶりへ
5. 🥩 厨房右の什器の**チャーシュー・ネギ**をタップ → 具が飛び出して、選んでいるどんぶりへ
6. 🙋 **お客さんをタップ**すると、その人の前のどんぶりを出します

## ゴミになるもの

- ピピッの後に放っておいた茹ですぎの麺
- トッピングをのせすぎたラーメン、注文とちがうラーメン
- 麺を入れたまま、お客さんが帰ってしまったラーメン

## キー操作（PC）

G 水 / Q 麺を入れる / W 麺を出す / A チャーシュー / S ネギ / 6〜0 席1〜5
