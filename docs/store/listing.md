## 日本語

**アプリ名**（30 文字以内）

```
行列のできるラーメン店
```

**簡単な説明**（80 文字以内）

```
注文どおりにラーメンを作って、カウンターのお客さんに出そう！おいしく早く出すほど評判が上がり、店の前に大行列ができる3D調理ゲーム。
```

**詳しい説明**

```
昭和レトロな小さなラーメン屋。カウンター6席に、お客さんが次々とやってくる。
注文どおりのラーメンを手早く作って出せば評判が上がり、店の前には大行列！
営業終了までに、どれだけ稼げるかに挑戦しよう。

■ 4種類のメニュー
・ラーメン／チャーシューメン／ネギラーメン／ネギチャーシューメン
・カウンターの注文札を見て、注文どおりに作ろう
・まちがえたラーメンや、ゆですぎた麺はゴミ箱行き

■ 本格的な調理の流れ
・空いている麺ゆで機に麺を入れる（6玉まで同時にゆでられる）
・どんぶりをタップしてスープを注ぐ
・「ピピッ！」と鳴ったら、てぼをタップ。湯切りして、どんぶりへ
・チャーシューとネギは、タップするとどんぶりへ飛んでいく
・できあがったラーメンは、自動でお客さんのもとへ

■ お水も忘れずに
・ラーメンは熱いので、お水がないとお客さんは食べてくれない
・空になったコップは、タップしておかわりを

■ 評判が上がると、行列が伸びる
・早くておいしいラーメンを出すほど評判が上がる
・お客さんが増えて、店内の行列は窓の外まで
・待たせすぎると、お客さんは怒って帰ってしまう

■ 3Dで描かれたラーメンとお客さん
・湯気の立つスープ、ちぢれ麺、厚切りチャーシュー、山盛りのネギ
・表情ゆたかなお客さんたち
・昭和の歌謡曲風BGMと、ジュワッ、ゴトッ、まいど！の効果音

■ その他
・「ふつうのラーメン屋」から「伝説の行列店」までの称号
・最高利益を記録。結果をSNSでシェアできる
・日本語／英語に対応
・広告が表示されます
